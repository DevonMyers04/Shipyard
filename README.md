# Shipyard

Shipyard is a collaborative software project management platform designed for
small development teams.

Teams can create projects, assign tasks, track progress, and monitor development
activity in one place.

## Version 1

The first version of Shipyard will support:

- Create projects
- View projects
- Create tasks
- Assign task status
- To Do / In Progress / Done workflow
- Kanban board
- Add comments to tasks
- Store application data in PostgreSQL

## Future Features
